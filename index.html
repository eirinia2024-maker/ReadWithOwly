Готовая система обучения чтению по-английски

Чёткая структура, допматериалы под любой темп и первые мини-тексты уже в начале курса.

Читаем с Аули (Read with Owly) — обучающий комплекс, который помогает ребёнку сформировать устойчивый навык чтения по-английски: не угадывать слова, а читать по звукам. В основе курса - британская методика «фоникс», широко используемая в школах Великобритании и доказавшая свою эффективность.

Кому подойдёт
  • Частным преподавателям — чтобы обучать чтению по системе, без “допиливания” и поиска допов.
  • Языковым школам — как отдельный курс чтения или модуль в программе.
  • Родителям — для занятий дома по понятной инструкции.

Почему phonics?

Метод обучения чтению через звукобуквенные соответствия, который помогает ребёнку не угадывать слова, а читать их самостоятельно.

Читаем по звукам

Ребёнок соединяет звуки и может прочитать новое слово, даже если видит его впервые.

Не угадываем по картинке

Формируется навык декодирования, а не запоминания формы слова.

Видимый прогресс

Первые мини-тексты появляются уже в начале курса.

О комплексе

Пособие построено на принципах phonics: ребёнок учится соединять звуки и читать новые слова. Подходит как для регулярной практики, так и для интенсивного курса.

Понятная система

Буква → звук → слоги → слова → короткие фразы и тексты. Постепенное усложнение без перегруза.

Два сценария занятий

15–20 минут на каждом занятии: 1–2 страницы параллельно с разговорным курсом.
Интенсив: 20 занятий по 40–60 минут.

Что внутри книги

Примеры страниц: чтение, письмо, восприятие на слух и мини-комиксы, страницы для закрепления и повторения.

Как использовать

Два режима работы — выбирай тот, который подходит для решения вашей задачи.

На каждом занятии (15–20 минут)

  1. Звук и артикуляция — послушать и повторить.
  2. Чтение — слоги/слова по изученным буквам.
  3. Внимание и слух — найти/обвести/соотнести.
  4. Письмо — обводка и написание.
  5. Мини-чтение — комиксы или задания на дополнительное чтение.

Интенсив (20 занятий по 40–60 минут)

  • Фиксированный план по юнитам (шаг за шагом).
  • Можно заниматься в каникулы.
  • Подходит для ускоренного старта чтения.
Подсказка: можно комбинировать оба режима — интенсивом пройти базу, а затем поддерживать навыки короткими занятиями.
